「専用洗剤をいくつも買わずに、重曹とクエン酸だけで水回りをきれいにできる?」——この記事はその疑問に答えます。結論から言うと、台所・洗面台・お風呂・トイレの大半の汚れは、この2つで対応できます。ただし「どっちをどこに使うか」を間違えると効果が出ません。まずその仕分けから整理します。

重曹とクエン酸、どっちをどこに使うのか

水回りの汚れは、大きく2種類に分かれます。汚れの正体が分かれば、使う物は自動的に決まります。

  • **油・皮脂・食べかすなどのベタつき汚れ → 重曹**(弱アルカリ性で、酸性の油汚れを中和してゆるめる)
  • **水あか・石けんカス・尿石などの白くこびりついた汚れ → クエン酸**(酸性で、アルカリ性のミネラル汚れを溶かす)

判断に迷ったら、触った感触で見分けます。ヌルッ・ベタッとしていれば重曹、ザラザラ・カチカチに固まっていればクエン酸、と覚えておくと現場で迷いません。

注意点として、重曹とクエン酸を同時に混ぜると中和して泡(二酸化炭素)が出るだけで、洗浄力はむしろ落ちます。「W使い」は順番に使うのが基本で、同時投入は排水口の発泡剤くらいにしか向きません。

まず作っておくと便利な2つのスプレー

掃除のたびに粉を出すのは手間なので、先にスプレーを用意しておくと一気に楽になります。

  • **クエン酸スプレー**:水200mlにクエン酸小さじ1を溶かす
  • **重曹スプレー**:水200mlに重曹小さじ1を溶かす(溶けにくいのでよく振る)

ペットボトルでも作れますが、空のスプレーボトルがあると使い勝手が段違いです。重曹は粉のまま「研磨剤」としても使うので、粉と水溶液の両方を用意しておくと守備範囲が広がります。

作り置きは水道水だと雑菌が増えやすいので、1〜2週間で使い切る量にとどめ、濁ってきたら作り直すのが無難です。

場所別・具体的な掃除手順

蛇口・シンクの白いくもり(水あか)

蛇口の根元やシンクのフチが白くくもるのは、水道水のミネラルが固まった水あかです。これはクエン酸の出番。

1. クエン酸スプレーをたっぷり吹きかける

2. キッチンペーパーをかぶせ、上からもう一度スプレーして「湿布」状態にする

3. 30分〜1時間ほど置く(頑固なものは2時間)

4. 古歯ブラシでこすり、水で流す

ポイントは「置く時間」。さっと拭くだけでは溶けきりません。蛇口を鏡のようにしたいなら、仕上げに乾いた布でから拭きすると白い跡が残りません。

コンロ周り・換気扇の油汚れ

ベタつく油は重曹。粉のまま振りかけて使うと研磨効果も加わります。

1. 汚れに重曹を粉のまま振りかける(または重曹スプレー)

2. 5〜10分置いて油をゆるめる

3. 丸めたラップやスポンジでこする

4. 固く絞った布で拭き取る

油が固まって取れにくいときは、40〜50度くらいのお湯で重曹を溶いてペースト状にすると密着して落としやすくなります。重曹は塗装やコーティングを削ることがあるので、目立たない所で試してから使うと安心です。

排水口のヌメリ・におい

ここは数少ない「2つを順番に使う」場面です。

1. 排水口に重曹を粉のままたっぷり(カップ半分ほど)振りかける

2. その上からクエン酸を重曹の半量ほどふりかける

3. コップ1杯のぬるま湯を回しかけると発泡する

4. 15〜30分置いて、最後に多めの水で流す

泡がヌメリを浮かせ、においも和らぎます。発泡は密閉空間に閉じ込めると圧がかかるので、フタはせず開けたまま行ってください。

お風呂・洗面台の2種類の汚れ

浴室は汚れが混在します。ザラつく白い汚れ(石けんカス・水あか)はクエン酸、ヌルつく汚れ(皮脂)は重曹と、場所で使い分けます。

  • 蛇口・鏡の白いうろこ → クエン酸湿布
  • 浴槽のフチのザラつき → クエン酸スプレー
  • 床や手すりの皮脂ヌメリ → 重曹をスポンジに付けてこする

鏡のうろこは特に手強く、一度で取れないこともあります。クエン酸湿布を繰り返すか、最後に重曹の粉で軽く磨くと取れる場合があります。

トイレの黄ばみ・輪じみ

便器内側の黄ばみや輪じみは尿石で、アルカリ性。クエン酸が合います。

1. クエン酸スプレーを輪じみ部分に吹く

2. トイレットペーパーを貼り付けて湿布する

3. 30分〜数時間置く

4. ブラシでこすって流す

軽い黄ばみは重曹を振りかけて磨くだけでも薄くなります。

失敗しないための注意点

  • **塩素系漂白剤(カビ取り剤など)とクエン酸を一緒に使わない**:有害なガスが発生します。これは絶対に守ってください。容器に「まぜるな危険」とある製品との併用は厳禁です。
  • **大理石・天然石・アルミ・鉄・大事な金属にクエン酸を使わない**:酸で変色やサビ、表面のくもりが起きることがあります。
  • **重曹で力任せにこすらない**:研磨作用があるため、ステンレスや人工大理石に細かい傷が付くことがあります。まず溶液で試すのが基本です。
  • **酸・アルカリを長く肌に付けない**:手荒れの原因になるので、長時間の作業や肌が弱い人はゴム手袋を使うと安心です。

なぜ「置く時間」が結果を分けるのか

重曹もクエン酸も、汚れを化学的にゆるめてから物理的に落とす道具です。市販の強力洗剤と比べると反応がおだやかなぶん、こする前に「反応させる時間」を取るかどうかで仕上がりが大きく変わります。すぐ拭いて「効かない」と感じるのは、たいてい時間不足が原因です。

逆に言えば、湿布して放置している間は手が空きます。クエン酸湿布を貼ったらその間に別の場所を重曹で磨く、という段取りにすると、洗剤を何本も持ち替えるより効率よく一周できます。2つの粉だけで水回りが回せるのは、こうした「待ち時間の使い回し」ができるからです。

まずはクエン酸スプレーと重曹の粉を1つずつ用意して、蛇口の水あかから試してみてください。落ちる手応えがつかめれば、ほかの場所にも応用が利きます。
